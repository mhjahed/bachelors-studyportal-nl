# Bachelors Portal NL
A student support platform for those pursuing bachelor studies in the Netherlands.

## TOOLS USED
- React 18 + Vite
- Bootstrap 5 + SCSS
- Boxicons
- React Router v6
- EmailJS (3 accounts)
- LocalStorage data layer
- JSON data files

## Development Setup
```bash
npm install
cp .env.example .env
# Fill in your EmailJS credentials in .env
npm run dev
